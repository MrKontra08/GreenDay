З ЧОГО ПОЧАТИ
1. Завантаж ZIP і розпакуй УСІ файли в одну папку.
2. Відкрий index.html подвійним кліком. Інтернет не потрібний.
3. Альтернатива: Grіndey_Frog_Archive_ONE_FILE.html (надається окремо) містить усе в одному файлі.

• 6 авторів, 10 днів активності, 150 переходів до повідомлень-відповідей.
• 29 медіавкладень: 14 фото, 3 стікери, 7 відео, 2 голосові, 3 файли.
• 1 опитування з усіма відповідями й голосами.
• Реакції (153 повідомлення), вкладення й оригінальний порядок.
• Оригінальний Telegram-експорт: messages.html + його css/, js/, images/ та всі медіа.

МОЖЛИВОСТІ
• Пошук по фрагменту тексту (зокрема підписах, назвах медіа, описах фото).
• Фільтри автора, дати, типу повідомлення, наявності реакцій та відповіді.
• Медіатека з повноекранним переглядом, відтворенням відео/аудіо.
• Пошук за зображенням: додай файл або перетягни на панель — отримаєш ранжування за схожістю.
  Точні копії зображень розпізнаються за контентним SHA-256, інші — приблизно за візуальними ознаками.
• Перехід до початкового повідомлення з будь-якого медіафайлу.
• Особисті закладки (зберігаються лише у браузері, через localStorage).
• Хроніка днів і статистика авторів.
• Гаряча клавіша Ctrl+K для пошуку, стрілки для галереї, Esc для закриття.

ПУБЛІКАЦІЯ
• Netlify Drop: перетягни розпаковану папку Grindey_Frog_Archive з index.html і рештою файлів.
• GitHub Pages: додай вміст папки Grindey_Frog_Archive у корінь репозиторію й увімкни Pages.
• Один HTML-файл також можна розмістити на хостингу, але багатофайлова версія легша для браузера.

ВАЖЛИВО ПРО ПРИВАТНІСТЬ
Це копія ПРИВАТНОГО листування з усіма наявними у файлі вкладеннями.

У сайту немає вбудованої серверної авторизації: приховати URL недостатньо для захисту.
Якщо хочеш обмежити доступ, використовуй приватний хостинг із реальною перевіркою входу.
Сайт не передає медіа, тексти, завантажені фото або пошукові запити на сторонні сервери.
Пошук за зразком — візуальна схожість, а не повноцінний AI-аналіз усіх об’єктів.
Звукові повідомлення в архіві не мають текстових транскрипцій; це не дописувалося.
